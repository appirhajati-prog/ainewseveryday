# 🤖 ربات اخبار روزانه هوش مصنوعی (AI News Everyday)

رباتی برای جمع‌آوری خودکار اخبار، ابزارها و ترندهای هوش مصنوعی از منابع معتبر، ترجمه به فارسی و ارسال به کانال تلگرام.

## 📌 منابع جمع‌آوری اخبار

| منبع | نوع محتوا |
|------|-----------|
| GitHub | مخازن ترند هوش مصنوعی |
| Hacker News | اخبار داغ جامعه تکنولوژی |
| Reddit | پست‌های ساب‌ردیت‌های AI |
| Hugging Face | مدل‌های جدید NLP |
| Product Hunt | ابزارهای جدید AI |

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather) دریافت کنید)

### مراحل نصب

1. **کلون کردن پروژه:**
   ```bash
   git clone https://github.com/appirhajati-prog/ainewseveryday.git
   cd ainewseveryday
   ```

2. **نصب وابستگی‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

3. **تنظیم متغیرهای محیطی:**
   ```bash
   cp .env.example .env
   ```
   سپس فایل `.env` را ویرایش کرده و توکن و چت آیدی خود را وارد کنید.

4. **اجرای ربات:**
   ```bash
   # اجرای یک‌باره (ارسال دیجست)
   python app.py

   # اجرای دائمی (هر روز ساعت 12:00)
   python app.py --daemon
   ```

## 🧪 اجرای تست‌ها

```bash
python -m pytest tests/ -v
```
یا با unittest:
```bash
python tests/test_services.py
```

│   ├── logger.py          #   پیکربندی لاگ‌ها

## ⚙️ تنظیمات قابل تغییر

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `TELEGRAM_TOKEN` | - | توکن ربات تلگرام |
| `CHAT_ID` | - | شناسه چت/کانال |
| `MAX_DIGEST_ITEMS` | 15 | حداکثر تعداد اخبار هر دیجست |
| `REQUEST_TIMEOUT` | 15 | تایم‌اوت درخواست‌ها (ثانیه) |

## 🔧 امکانات و بهینه‌سازی‌ها

- ✅ **ایمن‌سازی Markdown:** کاراکترهای رزرو شده تلگرام به‌صورت خودکار escape می‌شوند تا از خطای پارس جلوگیری شود
- ✅ **حذف همزاد هوشمند:** علاوه بر URL، عنوان‌های مشابه نیز تشخیص داده می‌شوند
- ✅ **ترجمه مقاوم:** برش هوشمند متن روی مرز کلمات + حفظ متن اصلی در صورت خطا
- ✅ **رتبه‌بندی:** اخبار بر اساس میزان تعامل (ستاره، آپ‌وت و...) مرتب می‌شوند
- ✅ **بج ترند:** خبر داغ هر منبع با 🔥 مشخص می‌شود
